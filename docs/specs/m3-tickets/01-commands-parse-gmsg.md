# 01 — commands_parse_gmsg 纯函数 + 单测

**What to build:** `/gmsg` 命令的参数切分能力：给定一行 `/gmsg 群名 消息`，解析出群名与消息两个部分。这是开发者可见的解析契约——群名取首个空白前的 token（上限 31 字符，超长拒绝），消息取其后全部内容（内部空格保留，为空拒绝），命令后多余空白跳过。以纯函数形式存在并可通过单元测试验证，是 /gmsg 命令与后续群聊功能的基础。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 黄金切分：`/gmsg 学习小组 今天学什么` → 群名=学习小组，消息=今天学什么
- [ ] 多空白：`/gmsg   学习小组   今天学什么` → 群名=学习小组，消息跳过前导空白
- [ ] 消息内部空格保留：`/gmsg 学习小组 今天 学 什么` → 消息=今天 学 什么
- [ ] 缺消息（`/gmsg 学习小组`）与缺群名（`/gmsg`、`/gmsg  `）均返回失败
- [ ] 群名超长（≥32 字符）返回失败
- [ ] test_commands 单元测试全部通过（与既有 parse_priv 用例同构，无框架 CHECK 宏风格）
