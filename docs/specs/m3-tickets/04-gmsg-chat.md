# 04 — /gmsg 群聊 + MSG_GMSG 分发

**What to build:** 用户输入 `/gmsg <群名> <消息>` 向群内发言：客户端经参数纯函数解析后构造请求帧发送；所有群成员（含发送者本人，与大厅广播同构的预期回显）收到 `[学习小组] 发送者: 消息` 形态的群聊帧并原样显示。非成员发言、向不存在的群发言收到对应错误帧；缺参/超长群名本地拒绝。

**Blocked by:** 01 — commands_parse_gmsg 纯函数 + 单测

**Status:** ready-for-agent

- [ ] 帧分发新增群聊消息处理：`[学习小组] alice: 今天学什么` 原样打印，不打断输入行
- [ ] `/gmsg 学习小组 今天学什么` 后，所有成员（含发送者本人）收到该群聊广播
- [ ] 非成员发言收到 `错误(201): You are not a member of this group`
- [ ] 向不存在的群发言收到 `错误(201): Group not found`
- [ ] 缺消息/缺群名本地提示用法；超长群名（≥32 字符）本地拒绝，不发送请求
