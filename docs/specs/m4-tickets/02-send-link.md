# 02 — 发送链路（/sendfile → 轮询分片 → 完成）

**What to build:** 发送方端到端可用：`/sendfile <目标> <文件>` 提交（本地校验 + 中文确认 + 服务器等待公告、从公告解析自己的传输标识）；对方接受后自动轮询分片发送（每轮 ≤4 片限流、发送期间聊天不中断、每 1MiB 进度行、发完自动发送完成帧）；对方拒绝/取消、断线、错误帧全部清理任务并释放槽位；发送方 `/cancel` 主动取消。帮助文本含 /sendfile 与 /cancel 说明。

**Blocked by:** 01 — 测试缝与协议构造器

**Status:** ready-for-agent

- [ ] `/sendfile` 提交：本地中文确认提示 + 服务器等待公告显示（含 `File transfer #N: ... Waiting for acceptance...`）；从公告解析出 tid 关联发送任务
- [ ] 空文件（0 字节）本地拒绝；文件打不开本地提示；目标不在线收到 `错误(200)` 且任务清理、槽位释放（可再次发送）
- [ ] 发送槽忙时第二个 `/sendfile` 本地拒绝并提示
- [ ] 收到接受公告/帧后自动开始分片：按序发送 chunk（tid+offset+data），单片数据 ≤65500 字节、每轮 ≤4 片（≈256KB 限流，不超服务器写缓冲）
- [ ] 发送期间可继续收发聊天消息（事件循环不冻结）；进度每越过 1MiB 打印一行（`发送中 #N: 已发/总字节 (百分比)`）
- [ ] 全部字节发完后自动发送完成帧；收到完成公告后任务清理、槽位释放
- [ ] 收到拒绝公告/帧 → 任务清理；收到取消帧/取消公告/断线公告 → 任务清理（发送方视角）
- [ ] 发送方 `/cancel <tid>` → 发送取消帧 + 本地任务清理；对未知 tid → 本地提示"没有 #N 的传输记录"不发送
- [ ] 错误帧(300) 到达且匹配活动任务 → 任务清理
- [ ] 帮助文本已含 `/sendfile <用户> <文件> 发送文件` 与 `/cancel <tid> 取消传输`
